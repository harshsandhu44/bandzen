# Guides

Guides are short reference pieces — the things worth reading once and coming
back to, rather than working through. They are free on every plan and there is
no limit on them.

## Finding one

They are grouped by **category** — strategies, reading, writing, vocabulary,
grammar, exam day, listening, speaking — and each carries a **level** and a
reading time.

Unlike [lessons](/candidates/lessons), guides do not have a Practice stage and
finishing one is not recorded. Nothing tracks whether you have read a guide.

## Listening and speaking guides

There are guides in the listening and speaking categories even though neither
module is built. That is deliberate rather than an oversight: advice about
predicting before the audio starts, or filling two minutes in Part 2, is useful
whether or not this product can give you an audio file to practise on.

They are reading, not practice, and they do not claim otherwise.

## Guides against lessons

|                   | Lessons                     | Guides             |
| ----------------- | --------------------------- | ------------------ |
| Shape             | Six stages, in order        | Prose              |
| Leads to practice | Yes                         | No                 |
| Progress recorded | Yes — counts as a study day | No                 |
| Grouped by        | Module, then depth          | Category and level |

If you are working through a technique, you want a lesson. If you want to check
something before an exam, you want a guide.
