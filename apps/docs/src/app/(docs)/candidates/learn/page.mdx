# Lessons and guides

Learn holds two different kinds of content, grouped by module on the Learn hub:
[lessons](/candidates/learn/lessons), which teach a technique across six
stages, and [guides](/candidates/learn/guides), short reads that each end by
pointing at something to practise.

All four modules — Reading, Listening, Writing, Speaking — have a card on the
Learn hub. Where a module's lesson catalogue is still being written, its card
says so rather than showing an empty list or a lock.
