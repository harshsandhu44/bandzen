# How practice works

Practice is where you attempt questions and get marked. It holds the four
modules, and a second way into the same content: sitting a test.

## By module

- [Reading](/candidates/practice/reading) — {FREE.practicePerModule} tests on
  Free, then Pro; unlimited on Pro.
- [Listening](/candidates/practice/listening) — {FREE.practicePerModule} tests
  on Free, then Pro; unlimited on Pro.
- [Writing](/candidates/practice/writing) — metered on Free; see
  [Plans and limits](/candidates/plans-and-limits).
- [Speaking](/candidates/practice/speaking) — Pro only.

Each module's own page lists what you can filter by, how long a session takes,
and exactly how it is marked.

## Sit a test

Two full sittings, each its own card with section, duration, difficulty and
whether you have already taken it: [the diagnostic](/candidates/the-diagnostic),
and the full four-skill mock test — Listening, Reading, Writing and Speaking
back to back, real IELTS order and lockstep, one overall band at the end. The
mock is Pro only, capped at one a week.
