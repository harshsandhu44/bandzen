# How practice works

Practice is where you attempt questions and get marked. It holds the four
modules, and a second way into the same content: sitting a test.

## By module

- [Reading](/candidates/practice/reading) — unlimited on every plan.
- [Listening](/candidates/practice/listening) — unlimited on every plan.
- [Writing](/candidates/practice/writing) — metered on Free; see
  [Plans and limits](/candidates/plans-and-limits).
- [Speaking](/candidates/practice/speaking) — Pro only.

Each module's own page lists what you can filter by, how long a session takes,
and exactly how it is marked.

## Sit a test

The same practice content, listed as a table: section, duration, difficulty,
and whether you have already taken it. Today this holds one entry —
[the diagnostic](/candidates/the-diagnostic) — beside a dashed, locked card for
the full four-skill mock test.

<Callout tone="locked" title="Not built">
  There is no single sitting that chains Reading, Listening, Writing and
  Speaking into one mock test yet. Every module it would draw on already has a
  marking engine — the sitting itself is what is still being built.
</Callout>
