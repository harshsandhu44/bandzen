# Listening

Listening practice is unlimited on every plan, including Free — the same
policy as Reading, and for the same reason: marking it costs nothing to run.

## Finding a track

The list can be filtered by **question type** — multiple choice, sentence
completion, or matching — and by **difficulty**.

## Sitting it

The audio plays once. There is no pause, rewind, or replay button, the same
constraint the real exam sets. Questions are answered as a batch alongside it.

While you work:

- **Flag** a question to come back to it. Flags are yours and are not marked.
- **Answers save as you type**, debounced, never blocked by anything.
- **Leaving is safe.** An attempt you have started but not submitted is still
  there when you come back. Starting from the list resumes it rather than
  beginning a second one.

## How it is marked

Listening is marked by the **identical pure function Reading uses**, on the
**same Academic Reading conversion table** — there is no separate Listening
band table yet. See
[How reading is marked](/candidates/practice/how-reading-is-marked) for
exactly how that works; everything there applies here too.

The review adds one thing Reading's does not need: the **transcript**, so you
can see what was said next to what you answered.
