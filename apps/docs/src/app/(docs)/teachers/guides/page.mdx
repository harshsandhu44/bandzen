# Guides

A guide is a short reference piece. Unlike a [lesson](/teachers/lessons) it has
no stages, and nothing records whether a candidate read it — though it can end
with a button into a drill, or into asking Coach.

<Callout title="Filed as Resources in the CMS">
  This page and the candidate-facing site both say "Guides". The CMS section,
  its route, and its table are named "Resources" — the content is identical, the
  name just differs by surface. Look for **Resources** in the CMS navigation.
</Callout>

## The fields

| Field         | Notes                                                                            |
| ------------- | -------------------------------------------------------------------------------- |
| Slug          | Unique across all guides                                                         |
| Title         | Sentence case                                                                    |
| Summary       | One line, shown in the list                                                      |
| Category      | Strategies, reading, writing, vocabulary, grammar, exam day, listening, speaking |
| Level         | Beginner, intermediate or advanced                                               |
| Minutes       | Reading time                                                                     |
| Module        | Optional — see below                                                             |
| Question kind | Optional                                                                         |
| Body          | Paragraphs                                                                       |

## Module is deliberately optional

Guides in the **listening** and **speaking** categories should have **no
module** set — the editor only offers Reading or Writing for this field, even
though Listening and Speaking are both practisable modules now. A listening or
speaking guide sits in the guides list and is readable with no module attached,
which is the only option the schema currently allows.

<Callout title="Category is not the same as the drill link">
  Setting a guide's **category** to listening or speaking files it correctly. It
  does not, and currently cannot, wire a "Practise this" button into the
  Listening or Speaking module the way a reading or writing guide's module field
  can — write the guide as advice rather than implying a practice link that is
  not there.
</Callout>

## Listed but not drafted

A guide with a title and no body shows in the list without being readable, the
same way an unwritten lesson does. It is a legitimate placeholder for something
planned.

## Choosing between a guide and a lesson

Write a **lesson** when there is a technique to be shown, tried and then drilled.
Write a **guide** when there is something worth knowing that does not need
practice — a reference list, a checklist, an explanation of what separates two
bands.
